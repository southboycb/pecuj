# Pečuj

Údržba aut a domácnosti na jednom místě. Data se ukládají v prohlížeči každého zařízení (zatím bez synchronizace).

## Zveřejnění přes GitHub Pages
1. Nahrajte všechny soubory z této složky do kořene repozitáře.
2. Settings → Pages → Source: *Deploy from a branch*, větev `main`, složka `/ (root)` → Save.
3. Za minutu je aplikace na `https://<uživatel>.github.io/<repozitář>/`.

## Na mobilu
- **Android (Chrome):** otevřete adresu → menu ⋮ → *Přidat na plochu* / *Instalovat aplikaci*.
- **iPhone (Safari):** otevřete adresu → Sdílet → *Přidat na plochu*.

Data z verze otevřené jako soubor se do webové verze nepřenesou samy – použijte v Nastavení *Stáhnout zálohu* a v nové verzi *Obnovit ze zálohy*.
